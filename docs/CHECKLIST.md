## 01. 확인 범위와 판정 기준

체크는 명시한 환경에서 확인했다는 뜻임. 브라우저 샘플 통과를 실제 도면 변환 성공으로 해석하지 않음. 미확인 항목은 체크하지 않으며, 새 변경 후 기존 결과를 그대로 재검증 결과로 사용하지 않음.

| 구분 | 결과 | 검증 범위 | 근거 |
|---|---|---|---|
| 3D 객체 검사 | 18개 통과 | 실제 샘플 형상, 재질, 카메라, 표시 상태 | [객체 검사](../app/web/tests/viewer-crosscheck.html) |
| Python 파일 처리 | 6개 통과 | 임시 폴더의 실제 파일 복사, 입력 검증, 결과 탐색 | [파일 처리 검사](../app/tests/test_jobs.py) |
| 화면 회귀 검사 | 통과 | 메뉴, 도면 선택, 분할, 사람 시점, 반응형 배치 | [화면 검사](../app/web/tests/workspace.html) |
| 연결 API 계약 검사 | 통과 | 대체 JS API를 통한 호출, 진행, 오류, 복구 | [연결 검사](../app/web/tests/bridge-crosscheck.html) |
| 실제 데스크톱 변환 | 미검증 | 네이티브 파일 선택, 파일 드롭, 변환 엔진 실행 | 필수 Python 패키지 미설치 환경 |

- [x] 상세 패널 접기 및 왼쪽 메뉴를 통한 다시 펼치기
- [x] 원본 도면 목록과 2D 도면 탭의 양방향 선택 동기화
- [x] 원도면 선택과 3D 단면층의 독립 유지
- [x] 3D·2D·분할 모드 전환 및 모델 재로드 후 모드 유지
- [x] 분할 경계의 키보드 조절, 최소 25%, 최대 75%, 더블클릭 초기화
- [x] 실제 분할 경계 드래그 시 비율 변경 확인, 50%에서 58%로 변경

### 나. 실제 3D 객체 상태

- [x] 샘플 3개 층과 실제 형상·디딤면 로드
- [x] 층 표시를 끄고 켤 때 실제 객체의 표시 상태 변경
- [x] 지붕 표시 전환 및 복원
- [x] 지상 대지 표시 전환 및 복원
- [x] 가구 표시 전환 및 복원
- [x] 건축 색과 분류 색 전환 시 실제 재질 교체
- [x] 선택층만 남기는 단면과 자르기 평면·단면 채움 생성
- [x] 단면으로 선택한 층도 표시 체크를 끄면 숨김
- [x] 요소를 숨긴 상태에서 단면을 변경한 후 다시 켜도 단면 채움 복원

- [x] 입력칸에 글을 쓰거나 3D 화면이 숨겨진 상태에서 이동 키 무시
- [x] 자동 회전 시 실제 카메라 변화 및 끄기 상태 확인

- [x] 실제 Three.js 벽 형상을 이용한 충돌 차단 및 숨긴 벽 제외

오른쪽 드래그는 실제 OrbitControls에 합성 포인터 입력을 전달한 검사임. 충돌 검사는 단순 벽 형상 기준이며, 모든 실제 도면의 충돌·계단 보행 품질을 보증하지 않음. 옥상 잔디·설비는 기존 설계에 따라 지붕 토글을 따름.

## 04. 재검증 방법

저장소 루트에서 실행함. Python 파일 처리 검사는 표준 라이브러리만 사용함.

```sh
python3 -m unittest discover -s app/tests -v
node --check app/web/js/main.js
node --check app/web/js/viewer.js
git diff --check
python3 -m http.server 8765 --bind 127.0.0.1 --directory app/web
```

브라우저에서 아래 검사 페이지를 각각 열고 결과를 확인함. 검사 후 콘솔 오류도 확인함.

- `http://127.0.0.1:8765/tests/workspace.html`: `PASS` 확인
- `http://127.0.0.1:8765/tests/viewer-crosscheck.html`: `passed: 18`, `failed: 0` 확인
- `http://127.0.0.1:8765/tests/bridge-crosscheck.html`: `PASS` 확인

변경한 JS가 재사용되는 경우 새로고침만으로 해결됐다고 판단하지 않음. 캐시를 비활성화하거나 다른 로컬 포트에서 다시 검사함.

실제 데스크톱은 [설치 안내](../README.md)의 대상 환경을 준비한 뒤 저장소 루트에서 `python -m app`으로 실행함. 03절의 각 항목에 사용 도면·운영체제·결과를 기록한 뒤 체크함.
