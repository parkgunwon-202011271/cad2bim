# cad2bim 남은 작업 및 우선순위

기준일: 2026.11.19.

기준 브랜치: `xxrin/workspace-layout`

관련 문서: [기능 검증 체크리스트](CHECKLIST.md)

## 01. 제품 목표와 적용 원칙

CAD 평면도를 층별 3D 모델로 옮기는 시간과 조작 부담을 줄이고, 사용자가 원도면과 변환 결과를 비교하여 빠졌거나 이상한 부분을 쉽게 확인하도록 지원함.

기존 룰 기반 변환을 기준으로 개선함. 인식 실패·내보내기 생략·원도면의 실제 누락을 구분하며, 변환에 실패했다는 이유만으로 도면에 요소가 없다고 판정하지 않음. 규칙 점수를 정확도나 정답 확률로 표시하지 않음.

난이도는 현재 코드와 의존성을 기준으로 한 상대 평가임. 구현 후 측정한 일정이나 성능 수치가 아님. 우선순위는 P0, P1, P2 순이며, 같은 단계에서는 아래 순서로 진행함.

## 02. 완료한 기반 작업

- [x] 왼쪽 작업 메뉴와 원본 도면·층·요소 패널 구성
- [x] 3D·2D·분할 보기 및 경계 크기 조절
- [x] 원본 도면 목록과 2D 탭 선택 연결
- [x] 마우스 그림·키보드 키 안내 및 사람 시점 안내
- [x] 단면층 숨김과 요소 복원 시 단면 채움 갱신
- [x] 사람 시점 상태에서 결과 재로드 오류 수정
- [x] 동일 이름 도면의 작업 파일 덮어쓰기 방지
- [x] 실제 객체 검사 18개, 파일 처리 검사 6개, 화면·연결 계약 검사 구성

완료 표시는 [체크리스트](CHECKLIST.md)에 명시한 샘플·검사 환경 기준임. 실제 DWG·DXF 변환 검증 완료를 의미하지 않음.

- [ ] 대상 운영체제에 실행 환경을 준비하고 실제 변환 흐름 검증

우선순위: P0

난이도: 중간

대상: [설치 안내](../README.md), [의존성](../requirements.txt), [앱 실행](../app/main.py), [변환 작업](../app/jobs.py), [재현 스크립트](../scripts/verify.py)

완료 기준: 설치한 Python 버전·운영체제·변환기 경로를 기록하고, 지원하는 DWG와 DXF 입력으로 변환 완료 및 결과 재열기 확인. 원본 도면을 보존하고 별도 결과 위치에서 검증.

검증 경계: 브라우저 샘플과 대체 API 통과를 실변환 통과로 대체하지 않음. 현재 확인한 Python 환경에는 pywebview·ezdxf·ifcopenshell 등의 필수 패키지가 없어 미실행 상태임.

### 나. 네이티브 파일 선택·드롭·실패 복구

- [ ] [체크리스트 03절](CHECKLIST.md#03-실제-데스크톱에서-남은-확인)의 수동 항목 수행

우선순위: P0

검증 경계: 현재 연결 검사는 대체 JS API를 사용함. 충돌 검사는 단순 벽 형상과 샘플 엘리베이터 기준이며, 모든 도면의 계단·문·난간을 포괄하지 않음.

## 04. P1 변환 기록과 검토 기능

### 가. 변환 기록 조사와 신뢰 범위 확정

- [ ] 실패·건너뜀·확인 필요 기록의 생성 지점과 저장 범위 조사

우선순위: P1, 후속 검토 기능의 선행 작업

난이도: 중간

대상: [IR 모델](../core/src/cad2bim/ir/models.py), [규칙 점수](../core/src/cad2bim/confidence/__init__.py), [파이프라인](../core/src/cad2bim/pipeline.py), [DAE 내보내기](../core/src/cad2bim/export/collada.py), [IFC 내보내기](../core/src/cad2bim/export/ifc.py), [결과 전달](../app/api.py), [요약 파싱](../app/jobs.py)

완료 기준: 각 기록을 생성 단계·도면명·층·객체 식별자·원본 핸들·좌표·사유·누락 필드로 정리. 실제 샘플 출력과 코드를 대조하고, 사용자에게 보여줄 수 있는 기록과 내부 진단에만 쓸 기록을 구분.

현재 확인: IR에는 source·source_handles·confidence·reasons·warnings·unsupported 구조가 있음. DAE·IFC 내보내기에는 skipped 계수와 생략 분기가 있음. 이것만으로 모든 실패 객체의 위치와 이유가 저장된다고 판단하지 않음. 현재 앱 API는 검토 항목을 전달하지 않음.

검증 경계: 규칙 점수는 정답 확률이 아님. 근거 없는 백분율과 임의의 누락 판정을 표시하지 않음.

### 나. 필요한 실패 기록 보강

- [ ] 조사에서 확인된 기록 공백에 한해 객체별 처리 결과 보강

우선순위: P1, 기록 조사 후 진행

난이도: 중간에서 높음

대상: [파이프라인](../core/src/cad2bim/pipeline.py), [DAE](../core/src/cad2bim/export/collada.py), [IFC](../core/src/cad2bim/export/ifc.py), [IR 모델](../core/src/cad2bim/ir/models.py)

완료 기준: 인식 실패·내보내기 생략·지원하지 않는 요소를 구분하고, 실패 이유와 가능한 원본 참조를 저장. 참조가 없으면 위치 미확인으로 기록. 알려진 실패 도면을 사용해 기록 건수와 실제 생략 대상을 대조.

검증 경계: 발견하지 못한 객체는 식별자 자체가 없을 수 있음. 기록 건수만으로 원도면의 누락률을 계산하지 않음.

### 다. 확인할 항목 목록

- [ ] 신뢰 범위가 확인된 기록을 결과 패널에서 검토할 수 있도록 연결

우선순위: P1, 기록 계약 확정 후 진행

난이도: 중간

대상: [Python API](../app/api.py), [JS 연결](../app/web/js/api.js), [화면 조립](../app/web/js/main.js), [UI 컴포넌트](../app/web/js/ui/components.js)

완료 기준: 도면·층·요소 종류·사유별 목록과 필터 제공. 필터 후 건수와 실제 목록 일치. 기록 없음, 조회 실패, 원본 위치 없음 상태를 구분.

검증 경계: 목록 제목은 확인 필요로 표현하고, 변환 실패를 실제 도면 누락으로 단정하지 않음.

### 라. 원도면과 모델의 해당 위치로 이동

- [ ] 검토 항목을 선택하면 근거가 있는 원본 위치와 모델 요소로 이동

우선순위: P1, 검토 목록과 좌표 매핑 확인 후 진행

난이도: 높음

대상: [IR 모델](../core/src/cad2bim/ir/models.py), [2D 이미지 생성](../app/plans2d.py), [2D 뷰어](../app/web/js/ui/plan-viewer.js), [3D 뷰어](../app/web/js/viewer.js)

완료 기준: 도면 식별자·단위·origin_offset·층별 배치·PNG 좌표 변환을 명시하고, 알려진 위치로 클릭 이동하여 실제 도면과 일치하는지 확인. 연결이 없는 항목은 자동 이동하지 않음.

검증 경계: 파일명이나 목록 순서만으로 원도면과 층을 연결하지 않음. 현재 2D 도면과 3D 단면은 독립 선택임.

### 마. 검토 상태와 메모

- [ ] 확인할 항목에 확인 완료·보류·메모 상태 기록

우선순위: P1, 검토 목록과 결과 식별 기준 확정 후 진행

난이도: 중간

대상: [Python API](../app/api.py), [결과 관리](../app/jobs.py), [화면 조립](../app/web/js/main.js)

완료 기준: 앱 재실행 후 상태 복원, 원본이나 변환 버전 변경 시 이전 메모의 적용 대상을 구분. 자동 판정과 사용자 확인 상태를 별도로 표시.

검증 경계: 사용자 확인 완료를 자동 인식의 정답으로 전용하지 않음.

## 05. P2 후속 검토

### 가. 모델 형상을 유지하는 재질 변경

- [ ] 기존 색상 보기와 구분되는 재질 변경 기능의 범위 검토

난이도: 중간

대상: [3D 뷰어](../app/web/js/viewer.js), [표시 도구](../app/web/js/main.js)

완료 기준: 벽·문·창의 위치와 치수, 모델 단위, 카메라가 바뀌지 않는 재질 적용·복원 흐름 정의. 변환·검토 기능의 P0·P1 완료 후 구현 여부 결정.

### 나. 형상을 보존하는 AI 시안

- [ ] 재질·조명 시안의 입력과 원본 모델 보존 조건 검토

난이도: 높음

대상: [기존 실사화 구현](../core/src/cad2bim/export/photoreal.py), [3D 뷰어](../app/web/js/viewer.js)

완료 기준: AI가 벽·개구부·간격·스케일을 변경하지 않도록 원본 모델과 시안을 분리하고 비교 기준 정의. 기존 실사화 옵션의 실제 구현 경로와 의존성부터 재확인.

검증 경계: 현재 기능 구현이나 품질 보증이 완료된 항목이 아님. 외부 유료 모델 호출은 모델·호출 상한·비용 범위를 먼저 확인하고 별도 승인 후 진행.

### 다. 실제 도면 누락 탐지

- [ ] 변환 실패와 구분되는 실제 도면 누락의 판정 기준 및 평가 데이터 정의

난이도: 매우 높음

대상: [인식 단계](../core/src/cad2bim/recognize), [평가 단계](../core/src/cad2bim/evaluation)

완료 기준: 무엇을 누락으로 볼지 건축 실무 기준과 원본 정답을 정의하고, 오탐·미탐을 분리 평가. 모델 생성 결과만으로 누락을 확정하지 않음.

## 06. 사용자 작업과 보류 범위

- [ ] 사용자가 제작한 최종 아이콘 파일 수령 및 별도 적용 요청 확인

아이콘 제작은 사용자가 직접 진행하며, 에이전트의 이미지 생성·형태 변경은 중단된 상태임. 적용 요청 전까지 추가 아이콘 작업을 진행하지 않음.

LUW의 가져오기·저장·AI 기능은 실제로 검증된 범위만 참고함. 공개 HTML 문구나 클릭 가능한 버튼의 존재만으로 정상 동작을 전제하지 않음. 현재 TODO의 우선순위는 cad2bim의 변환 시간 단축과 검토 흐름 개선을 기준으로 함.
