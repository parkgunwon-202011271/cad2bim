# 공개 시험 데이터

다른 컴퓨터에서 도면을 따로 받지 않고 바로 시험하기 위한 데이터입니다.
물류 도면과 출처가 불분명한 외부 도면은 이 폴더에 넣지 않습니다.

| 폴더 | 내용 | 용도 | 조건 |
|---|---|---|---|
| `주민센터/` | 평면 DWG 3장, 정답 모델 `주민센터 모델링.skp` | 개발용. 벽 점수를 재는 기준 | 사용자 확인: 공개 가능 |
| `cc0/dev/` | Innerscene 도면 8장 | 개발용 | CC0, `cc0_manifest.json`, `terms.html` 참고 |
| `cc0/test/` | Innerscene 도면 4장 | **시험용** | CC0 |

시험용은 일반화 판정에만 씁니다. 결과를 보고 규칙을 고치지 말고, 규칙을 확정한 뒤 숫자만 측정합니다.
