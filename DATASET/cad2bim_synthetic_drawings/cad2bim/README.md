# CAD → BIM 테스트용 가상 도면

실제 도면 없이 변환 코드를 개발·테스트하기 위한 **가짜 도면**입니다. 모든 평면은 지어낸 것이며, 받은 실무 도면은 이 폴더에 넣지 않습니다.

## 파일

| 파일 | 평면 | 작성 습관 | 확인하려는 것 |
| --- | --- | --- | --- |
| `A1_retail_clean_en` | 근생 1층 (18×12m, 기둥 12개) | 영문 표준 레이어, 문·창·위생기구 블록, 벽은 LINE | 기본 인식이 되는가 |
| `A2_retail_messy` | 위와 같음 | 거의 모든 것이 레이어 `0`, 블록 분해, 중복선, 3mm 틈, 객체별 색, 단위 미지정 | 레이어에 기대지 않고 기하만으로 인식되는가 |
| `B1_apt_clean_kr` | 공동주택 단위세대 (10.8×8.4m, 벽식) | 한글 레이어(`벽체-RC`, `창호` 등), 한글 블록명, 벽은 닫힌 폴리선 | 한글 레이어명 해석, 기둥 없는 구조 |
| `B2_apt_partial_code` | 위와 같음 | 약어 레이어(`CON`, `BLK`, `WIN`), 일부만 지저분함 | 아래 함정을 잡아내는가 |

`B2`의 함정:
- 현관 칸막이(W10)가 두께 없이 선 한 줄로만 그려짐
- 조적벽 해치가 `DIM` 레이어에 잘못 들어감
- 가구 블록이 `UNIT-FUR` 블록 안에 중첩됨
- 창 블록 하나(`W`)를 비균등 축척으로 늘려 모든 창에 사용

두 평면 모두 일부러 넣은 상황:
- 공동주택의 거실·주방은 벽 없이 트여 있어 닫힌 영역 하나에 실명이 둘 (`shares_region_with`)
- 도곽, 표제란, 그리드, 치수, 계단, 가구처럼 벽이 아닌 선이 많음
- 문틀, 창, 기둥 때문에 벽 외곽선이 여러 조각으로 끊김

## 정답 파일 (`*.truth.json`)

각 DXF와 같은 이름입니다. 변환 결과와 비교해 재현율 같은 숫자를 계산할 때 씁니다.

- `walls`: 중심선 시작·끝점, 두께(mm), 재료(`RC`/`BLOCK`)
- `columns`: 중심점, 크기
- `openings`: 문·창의 위치, 폭, 소속 벽. 문은 경첩 위치와 열리는 방향 포함
- `rooms`: 실명, 라벨 위치, 순면적(㎡), 같은 영역을 쓰는 실
- `layer_classes`: 레이어 → 요소 종류. 레이어 분류기 테스트용
- `quirks`: 그 파일에 넣은 함정 목록
- `counts`: 요소별 개수

## 다시 만들기

```bash
pip install ezdxf shapely matplotlib
cd synth
python generate.py --out ../out    # DXF + 정답 JSON
python preview.py ../out           # 미리보기 PNG
```

평면을 바꾸거나 추가하려면 `synth/layouts.py`, 작성 습관을 바꾸려면 `synth/generate.py`의 `LAYER_SCHEMES`와 `VARIANTS`를 고칩니다.

## 실제 도면 취급 규칙

- 실제 도면은 이 저장소 밖 폴더에 두고, 경로는 실행할 때 인자로만 넘깁니다.
- 실제 도면에 대한 결과는 개수·비율 같은 집계 숫자만 공유합니다. 레이어명 원문, 좌표, 실명, 캡처 이미지는 공유하지 않습니다.
